# NC3 Teacher Resource for Variables in SwiftUI 
This repository has a completed Xcode Project, a YouTube video link of instructions, and a cheat sheet to help you teach variables in SwiftUI. 

## Objectives 
* Instantiate a variable with its type
* Add images to the Assets and add them to a view
* Create a custom SwiftUI View
* Add variablity to the view by having variables that change the modifiers
* Research different modifiers on an Image
* Troubleshoot compilation errors
